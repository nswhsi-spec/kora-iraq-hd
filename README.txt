كورة العراق HD Pro v6 — مشروع ويب + وسيط API

المزايا التي أضيفت:
- جدول مباريات اليوم وباچر و7 أيام، مع عرض التوقيت بتوقيت بغداد.
- تكامل واجهة لنتائج حقيقية عبر football-data.org API عند إعداد الخادم والمفتاح.
- جلب ترتيب الدوريات والهدافين عبر API.
- تفاصيل المباراة والأهداف والبطاقات والتبديلات عندما يوفرها المزود.
- طلب إشعارات المتصفح وتنبيه أهداف أثناء بقاء الصفحة مفتوحة.
- مشغل فيديو لرابط بث رسمي ومدعوم.
- ملف manifest وService Worker كأساس PWA.
- ملف server.js كوسيط يحفظ API token على الخادم ولا يضعه داخل واجهة المتصفح.

تشغيل الخادم:
1) تحتاج تثبيت Node.js 18 أو أحدث.
2) فك ضغط الملف وافتح Terminal داخل المجلد.
3) سجّل للحصول على مفتاح API من https://www.football-data.org/ ثم راجع التغطية والخطة.
4) عيّن متغير البيئة FOOTBALL_DATA_TOKEN إلى المفتاح. مثال في Linux/macOS:
   export FOOTBALL_DATA_TOKEN="YOUR_TOKEN"
   node server.js
   في Windows PowerShell:
   $env:FOOTBALL_DATA_TOKEN="YOUR_TOKEN"
   node server.js
5) افتح http://localhost:8080

ملاحظات مهمة:
- هذا المشروع ليس APK جاهزاً؛ إنه مشروع ويب قابل للتشغيل والبناء لاحقاً كتطبيق أندرويد باستخدام Android Studio/Capacitor.
- النتائج لا تصبح حقيقية إلا بعد إعداد المفتاح وتشغيل الخادم بنجاح. دون ذلك تظهر بيانات توضيحية.
- تغطية الدوريات العراقية والتشكيلات والإحصائيات تختلف حسب مزود البيانات وخطتك؛ football-data.org لا يضمن كل المسابقات.
- الإشعارات هنا أثناء فتح الصفحة فقط. إشعارات الخلفية تتطلب Push service / إعداد تطبيق أصلي.
- PWA وService Worker يتطلبان localhost أو HTTPS عند النشر، وليس فتح الملف مباشرة من مدير الملفات.
- مشغل الفيديو لا يتجاوز DRM أو قيود المواقع، ويحتاج رابط بث رسمي وصيغة مدعومة.
- لا تنشر مفتاح API داخل HTML أو على مستودع عام.
- لا يوجد APK مبني ضمن ZIP لأن بناء APK يتطلب بيئة Android/Gradle ومفاتيح توقيع عند الحاجة.
